# 🎙️ ChatVoice

**ChatVoice** — программа для озвучивания сообщений из чата во время стримов.

Поддерживается подключение сразу к нескольким платформам с последующей озвучкой сообщений с помощью Microsoft Edge TTS.

---

# Возможности

## Поддерживаемые платформы

- ✅ YouTube
- ✅ Twitch
- ✅ Kick
- 🔜 TikTok
- 🔜 Discord

---

## Озвучка

- Microsoft Edge TTS
- Высокое качество голосов
- Мужские и женские голоса
- Настройка скорости
- Настройка громкости
- Настройка высоты голоса

---

## Фильтрация сообщений

- Игнорирование команд
- Игнорирование ссылок
- Игнорирование пустых сообщений
- Игнорирование повторяющихся сообщений
- Ограничение длины текста
- Черный список пользователей
- Белый список пользователей
- Замена эмодзи словами

Пример:

```
😂 → смеётся
❤️ → сердце
👍 → палец вверх
🔥 → огонь
```

# Конфигурация

Настройки находятся в файле

```
config.json
```

Основные параметры

### Голос

```json
"default_voice": "ru-RU-DmitryNeural"
```

### Скорость

```json
"rate": "+0%"
```

### Громкость

```json
"volume": "+0%"
```

### Высота голоса

```json
"pitch": "+0Hz"
```

# Использование

1. Запустить программу.
2. Вставить ссылку на трансляцию YouTube.
3. Выбрать голос.
4. Нажать **Подключиться**.
5. Программа начнет получать сообщения из чата.
6. Все сообщения будут проходить фильтрацию.
7. После фильтрации сообщения помещаются в очередь.
8. Сообщения озвучиваются по очереди.
